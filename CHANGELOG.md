# Changelog

All notable changes to Macro Recorder are documented here using
[Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-11-05

First public release.

### Added

- Keyboard, mouse and gamepad recording, an editable timeline and concurrent native playback.
- Global shortcuts, pixel triggers, condition waits, background-window input and an emergency stop.
- Virtual Xbox 360 and DualShock 4 playback through ViGEmBus, with optional HidHide support.
- Import from AutoHotkey, AutoIt, TinyTask, Razer Synapse, Jitbit and AMC; export to AutoHotkey v2 and `.mrmacro`.
- Library folders and backups, timing diagnostics and run history.
- English and Russian interfaces, light and dark themes, overlays and a bind map.
- Portable build and installer, with checksums.
